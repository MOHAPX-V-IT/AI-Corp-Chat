# Contributing / Участие в разработке

**EN:** Open an issue describing the user-visible problem, affected module, reproduction steps and expected result. Use synthetic files and remove credentials, names and employee records. Install locked dependencies (including both nested modules), run `npm run test:portable`, `npm run check:public`, and `npm run build`. Add focused tests for meaningful behavior changes. Update both README languages and module documentation when configuration or permissions change. Preserve upstream license notices. Changes to external providers need a documented integration test and must not introduce live keys.

**RU:** Опишите в issue проблему пользователя, модуль, шаги воспроизведения и ожидаемое поведение. Используйте синтетические документы, удаляйте ключи и персональные данные. Установите зависимости по lock-файлам, включая вложенные модули; выполните `npm run test:portable`, `npm run check:public`, `npm run build`. Добавляйте содержательные тесты при изменении поведения. Обновляйте обе языковые версии README и документацию прав доступа/настроек. Сохраняйте лицензии исходной платформы. Для интеграций документируйте проверку без включения рабочих ключей.
