Для сохранения месяцев period:month. Нужна колонка настоящего месяца (например «Календарь.Период», «янв 2025»), а не только «Год». Программа понимает русские месяцы и ГГГГ-ММ. Неполный год подписывается фактическим диапазоном и не участвует в CAGR полных лет. Никогда не складывай год с его же январем–апрелем. Для brandMean сохраняется сумма и количество исходных цен: среднее внутри торгового наименования; среднее категории — среднее этих товарных цен. Для weighted цена равна рубли/упаковки. Совпадение SKU по разным месяцам и регионам — НЕ дубль. Полный повтор SKU × месяц × регион блокирует расчет и требует исследования. Укрупнение разных стран/каналов запрещено: сначала фильтр. registration нельзя заполнять признаком Rx/OTC или отсутствием БАДа.

Нормализация дает промежуточные записи с происхождением каждой строки и контрольными суммами; ошибки этих инструментов исправляй по исходным строкам. Не выдумывай SKU для обхода ошибки дубликатов. Параметры нормализации и filters сохраняются при частичной правке mapping; чтобы убрать фильтры передай filters:[], чтобы отменить нормализацию — normalization:null.
